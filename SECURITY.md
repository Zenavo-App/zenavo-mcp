# Security policy

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/Zenavo-App/zenavo-mcp/security/advisories/new) for this
repository. Do not open a public issue. We aim to reply within three working days.

In scope: this program, for example a way for a model or a service's output to make zenavo-mcp send the API key
somewhere else, reveal configuration values, or call the API in a way the key's permission should not allow.
Problems in the Zenavo service itself are welcome through the same channel.

Supported versions: the latest release.
